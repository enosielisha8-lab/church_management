Church Management System
Church Management System developed using PHP PDO, MySQL, AJAX, JavaScript, HTML5, and CSS3. The system helps churches manage members, attendance,  events, donations, and other administrative activities efficiently.


Project Overview
This system was designed to simplify church administration by providing a centralized platform where church leaders can manage church information digitally.

The system supports:
Member Management
Attendance Tracking
Event Management
Ministry Management
Donation and Offering Records
User Authentication
Dashboard Statistics
Responsive User Interface
